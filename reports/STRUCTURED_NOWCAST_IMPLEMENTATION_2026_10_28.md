# Structured nowcast — foundation implementation

## Status

Implemented and unit-tested locally on the October-testing branch. This is a development API, not a new activated app forecast or a fitted parameter set. Main, the existing forecast selection, Google Sheets and ON special-prior source rows are unchanged. No new election-result comparisons are claimed in this stage.

The user has approved a coherent nowcast framework covering all 88 districts and all six categories, rather than successive minor adjustments aimed at a target number of safe seats. The exercise concerns present support, not movement to election day.

## Scenario-derived lean tables

The user confirmed that AVERAGE PRIMARY LEANS and copied primary/2PP/2CP range tabs were generated by running many scenarios through the deterministic calculator. They are model-behaviour diagnostics, not independent evidence of forecast errors. Using those ranges to calibrate forecast uncertainty would be circular.

Located local methodology: `election-website/data/primary-leans-exhaustive/primary_leans.md`, its JSON export, and `outputs/primary-leans-20261028/build.mjs`. The local primary export describes 6,125 equally weighted scenarios (the user recalled 6,250); this count difference does not affect the provenance conclusion. The documented grid is explicitly a display convention, not a probability distribution, and excludes temporary retirement/sophomore effects. Do not interpret these fixed scenario weights as a prior over election outcomes.

## What the implementation adds

### District-lean errors

`SRC/nowcast_uncertainty.py` implements explicit per-party local, geographic and seat-class error scales; a validated six-party correlation matrix; optional variance-matched multivariate heavy tails; blended upper-house/subregion geography; and per-seat context scaling. A shared multivariate tail multiplier preserves joint party-substitution directions rather than independently inflating each party.

This represents uncertainty around the current geographic template, not just changing concentration of that template. However, its marginal shape overlaps with existing additive residual error. A new name alone does not produce a more credible uncertainty model: the scales, covariance and context allocation must be justified and estimated where possible. No fitted parameters are invented by this module.

The new regional/local/class budget REPLACES the ordinary regional/local primary residual when selected. Concentration and old local-noise shape trials cannot be stacked on it. Class and region are potentially correlated; class scale defaults to zero and must not be assigned an independent full-size error without evidence. Input errors are specified before clipping and statewide balancing; realised seat-level variances/correlations will differ.

Production seat totals and actual party column totals are preserved. Exact zero support stays zero; tiny positive primaries are not treated as proof of candidacy. No alternative strength map or new candidate roster is fabricated.

### Preference transport uncertainty

Separate optional source/origin/recipient discrepancy factors model systematic uncertainty in applying a source to the present contest. They are drawn once per election and reused coherently across seats and continuing fields. Source families are exact non-ON VEC, federal-evidence blend, special prior, and generic/synthetic fallback.

Transport factors are additional to the existing provisional flow perturbations and must therefore be explicitly budgeted; the current source SDs are not empirically fitted sampling errors. All new transport scales default to zero. This distinction allows an eventual estimate of evidence precision to coexist with uncertainty about federal-to-state or historical-to-current applicability. It does not automatically estimate either component.

The source rows remain unchanged. A simulation can fluctuate around a locked special-prior flow; the central engine's lock against generic anchoring/geography/siphon remains intact. This is not a replacement of the preference evidence hierarchy or a mixture of unapproved preference architectures.

### Candidate/context strength

An optional district/party context can multiply local error and supply an explicit zero-centred candidate-strength SD. Candidate-strength uncertainty requires a note documenting its reason. No electorate receives such an effect automatically. This stage concerns strength uncertainty for an existing modelled field, not nomination/appearance probabilities or synthetic candidates; candidate-field uncertainty remains a separate unfinished component.

## Development interface

Pass an explicit dictionary as `experiment['structured_nowcast']` to `simulate`. Required field: `provenance` (nonempty explanation). Optional fields:

| Field | Meaning |
|---|---|
| `local_sd_pp` | Party → local district-lean input SD, percentage points |
| `region_sd_pp` | Party → shared geographic input SD, percentage points |
| `class_sd_pp` | Party → shared seat-class input SD, percentage points |
| `correlation` | 6×6 positive-semidefinite unit-diagonal matrix in PARTIES order |
| `tail_df` | Optional Student-t degrees of freedom >2; covariance matched before balancing |
| `contexts` | District → documented local multipliers and candidate-strength SDs |
| `transport_log_sd` | Source family → systematic source-applicability log-weight SD |
| `provenance` | Data basis or explicit provisional-assumption label |

All omitted scales are zero; omitted correlation is identity, not an empirical estimate. This is deliberately not an automatically enabled numerical configuration. Normalised configuration is included in the returned experiment metadata and source fingerprints.

The ordinary random stream is advanced consistently when replacing old primary residuals, so paired statewide draws remain identical. New latent factors use separate reproducible random streams. No output is cached across different configurations or runs.

## Validation

34 targeted tests passed: existing engine, pattern and subregion tests plus eight new structured-nowcast tests. Checks cover:

- covariance validation, including singular valid matrices;
- empirical draw covariance and variance-matched tails;
- zero-uncertainty identity;
- immutable inputs, preserved exact zeros, nonnegative votes;
- conserved seat and production-party totals;
- geographic and candidate-context effects;
- coherent source-specific transport with unchanged source priors;
- transport operating even if all older preference SDs are zero;
- deterministic replay and identical paired statewide draws;
- rejection of stacked old/new primary uncertainty models.

An additional replay compares the unselected ordinary engine with three archived baseline election draws. Broader empirical calibration is NOT established by these engineering checks.
